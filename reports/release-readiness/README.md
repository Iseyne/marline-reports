# Release Readiness

Материалы по теме «Предрелизная подготовка в системе MarLine»: аннотация
и текст отчёта.

| Файл | Содержание |
|---|---|
| `annotation.tex` | Исходник аннотации |
| `annotation.pdf` | Собранная аннотация для отправки |
| `report.tex` | Исходник отчёта |
| `report.pdf` | Собранный отчёт |

## Сборка

Оба документа собираются под XeTeX с `fontspec` и `polyglossia` — обычный
`pdflatex` на них падает из-за кириллицы.

    latexmk -xelatex annotation.tex   # шрифты Liberation
    latexmk -xelatex report.tex       # шрифты FreeSerif / FreeMono

## Разделы отчёта

1. Введение
2. Постановка задачи
3. Обзор
4. Описание предлагаемого решения
5. Апробация / Эксперименты / Тестирование
6. Заключение
