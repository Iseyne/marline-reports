# Прогресс по задачам практики

## Задача 1. Данные для проверки

Написал детерминированный синтетический генератор набора данных
(`marline/tests/common/mod.rs`): один сид — один и тот же набор байтов между
запусками. Код покрывает точные дубликаты, почти-дубликаты (версии с
локальными правками), несвязанные документы и граничные размеры — пустой, в
один байт, на границах чанка.

## Задача 2. Интеграционные тесты

Добавил E2E-тесты для обеих ветвей: запись → чтение → scrub → повторное чтение
с проверкой байт-в-байт, восстановление версий через дельта-цепочки,
проверку, что несвязанные документы не уходят в дельты. В тестах выведены
метрики через `--nocapture`: коэффициенты дедупликации, число дельт, экономия.

## Задача 3. Дефекты

Устранил недетерминизм коэффициентов хешеров (фиксированный сид + splitmix64),
валидацию `sampling_rate`, панику на пустом чанке, некорректные
`next_hash`/`last_hash`, деление на ноль при нулевом тире и ошибки семантики
индекса (пересечения, повторный учёт признаков). К каждому фиксу — репро-тест:
sketcher 9/9, palantir 6/6.


## Замечания

Пока изменения были сделаны в локальном форке репозитория и не влиты в основной. В ближайшее время планируется продолжение работы над багфиксом и увеличением датасетов для различных сценариев.
